# География рода Нины Борисовой

Интерактивная карта семейного исследования: 282 человека с географической привязкой, 14 мест и 13 групп перемещений. Адаптирована для телефона.

## Открыть карту

Страница `index.html` содержит данные, стили и Leaflet 1.9.4. На HTTPS-хостинге подложка загружается из OpenStreetMap. Интернет нужен для картографических тайлов; при открытии через `file:` остаются карточки и отметки без подложки.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, затем `main` и `/ (root)`, Save. Для Pages из приватного личного репозитория нужен подходящий тариф GitHub, например Pro. Настройка видимости репозитория не изменяется.

Опубликованный сайт Pages может быть доступен всем, даже когда репозиторий приватный. Если требуется закрытая семейная карта, нужен хостинг с аутентификацией.

## География и источники

Маркеры обозначают поселения или широкие области, без адресов домов. У каждой привязки есть пояснение точности и основания. Люди без известной географии не нанесены. Пунктир показывает направление между известными местами жизни; он не воспроизводит точную дорогу. Версия о Белом озере включается отдельно, без приписывания проживания конкретным людям.

Сведения актуализированы 15 ноября 2026 года. Современные места: Алексей — Санкт-Петербург, Елена Владимировна Махонина — Череповец.

## Индексация

В HTML заданы `noindex,nofollow,noarchive,nosnippet,noimageindex`. `robots.txt` действует только из корня домена; в подпапке проекта Pages он не запрещает обход всего домена. Эти указания зависят от соблюдения роботами и не являются ограничением доступа.
